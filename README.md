# Sales Analysis Project

## Project Overview

This project focuses on analyzing sales data to understand sales performance, customer behavior, product performance, and overall business trends.

The project was completed using Excel, SQL, and Power BI. The data was analyzed and prepared in Excel, SQL was used to query and analyze the data, and Power BI was used to create an interactive dashboard for visualization and reporting.

## Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI

## Project Work

### Excel

- Data cleaning and preparation
- Sorting and filtering data
- Removing duplicate records
- Using Excel formulas for analysis
- Creating Pivot Tables
- Performing sales and customer analysis
- Summarizing important business information

### SQL

- Data filtering and querying
- Using aggregate functions such as SUM, COUNT, and AVG
- GROUP BY and ORDER BY
- Date-based analysis
- Monthly sales analysis
- Customer analysis
- Product analysis
- Generating useful business insights using SQL queries

### Power BI

- Importing and transforming data
- Creating data visualizations
- Creating charts and tables
- Building an interactive sales dashboard
- Analyzing sales trends
- Presenting key business insights

## Key Analysis

The project includes analysis of:

- Total sales
- Monthly sales trends
- Customer-related analysis
- Product performance
- Sales performance
- Sales trends over time
- Overall business performance

## Dashboard

An interactive Power BI dashboard was created to provide a visual overview of the sales data.

The dashboard helps users understand sales performance, identify trends, and explore important business information through interactive visualizations.

## Data Source

The dataset used in this project was obtained from Maven Analytics sample datasets.

**Source:** [Maven Analytics](https://mavenanalytics.io/)

## Files Included

- Excel workbook containing data analysis and Pivot Tables
- SQL file containing queries used for data analysis
- Power BI file containing the interactive dashboard
- README.md containing project documentation

## Objective

The main objective of this project is to practice and demonstrate data analysis skills using Excel, SQL, and Power BI.

The project demonstrates how raw sales data can be analyzed, transformed, and presented through meaningful insights and interactive visualizations.
